# Muhammad Awais — Portfolio

Static portfolio site (HTML + CSS + JavaScript, no build step).

## Run locally
Open `index.html` in a browser, or:

    php -S localhost:8000

## Deploy free on GitHub Pages
1. Create a repo named `Awais660.github.io` on GitHub.
2. Push these files:

        git init
        git add .
        git commit -m "Portfolio"
        git branch -M main
        git remote add origin https://github.com/Awais660/Awais660.github.io.git
        git push -u origin main

3. Site goes live at https://awais660.github.io (Settings → Pages if needed).

## Editing
- Text/content: `index.html`
- Colors: CSS variables at the top of `style.css`
- Photo: `assets/profile.jpg` · CV download: `assets/Muhammad_Awais_CV.pdf`
- Featured project screenshots: `assets/projects/`
